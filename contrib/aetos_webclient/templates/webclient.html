This template wins over Evennia's own `webclient.html` because a game prepends the Aetos template directory to `TEMPLATES[0]["DIRS"]` (see README.md). It cannot be found by the app-directory loader alone: Django searches every DIRS entry before any installed app, and Evennia always has its own webclient template directory in DIRS. Aetos extends its own base (`aetos/base.html`) rather than Evennia's stock `webclient/base.html`. The stock base loads eight third-party CDN resources for the benefit of the stock GUI; Aetos is vanilla JavaScript and uses none of them. See `aetos/base.html` for the full reasoning.
